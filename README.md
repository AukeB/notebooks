# Notebooks

This repository contains different kinds of notebooks.

**Notebooks**:

- `speech_to_text.py`: 🎙️ Downloads audio from YouTube, transcribes it using OpenAI Whisper, merges the transcript with timestamps, and splits the result into manageable text chunks for further processing.

- `image_to_text.py`: Notebook for converting all the images inside a specific directory to text, merging all the text together into a single .txt file.
